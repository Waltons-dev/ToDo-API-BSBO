# ToDo лист API

API для управления задачами с использованием матрицы Эйзенхауэра. Задачи делятся на 4 квадранта (Q1-Q4) по важности и срочности.

## Возможности

- Просмотр всех задач
- Фильтр по квадранту и по статусу (выполненные / невыполненные)
- Получение задачи по ID
- Статистика по задачам
- Поиск по названию и описанию

## Технологии

- Python 3.10+
- FastAPI
- Uvicorn

## Запуск

```bash
# 1. Клонировать репозиторий и перейти в папку проекта
git clone <ссылка-на-репозиторий>
cd <папка-проекта>

# 2. Установить зависимости
pip install fastapi uvicorn

# 3. Запустить сервер
uvicorn main:app --reload
```

После запуска:

- API: http://127.0.0.1:8000
- Документация (Swagger): http://127.0.0.1:8000/docs
